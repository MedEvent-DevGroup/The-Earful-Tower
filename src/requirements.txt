#   - matplotlib is imported eagerly by pyannote but not declared as a dep
# Gradio dropped — its dependency on huggingface_hub>=0.33.5 conflicts with pyannote 3.3.2
# Using CustomTkinter instead (proper desktop app, zero web-server conflicts)
#
# torch held at 2.4.1 despite Dependabot alerts. torch 2.6+ flipped
# torch.load(weights_only=True) by default, which breaks pyannote.audio 3.3.2 model
# loading (omegaconf.ListConfig not in safe-globals allowlist) and speechbrain 1.0.2
# checkpoint loading. Bumping to 2.8+ requires either a safe-globals shim or upgrading
# pyannote to 4.x (API changes).
# Reachability: this is a local desktop app that loads only trusted HuggingFace models
# (faster-whisper uses CTranslate2, not torch.load). The app calls none of the flagged
# torch APIs (verified via grep — no torch.load/jit.script/etc. in src/). All alerts are
# crafted-tensor memory-corruption or local-DoS, not reachable from the audio pipeline;
# the RCE alert needs an attacker-controlled checkpoint we never load.
